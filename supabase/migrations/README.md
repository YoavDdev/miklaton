# מיגרציות

התיקייה ריקה בכוונה. נקודת ההתחלה היא `supabase/baseline/0001_baseline.sql`
— צילום מלא של הסכימה שנוצר מהפרודקשן ב-2026-08-18. כל מה שקדם לו נמצא
ב-`supabase/archive/` ואין להריץ אותו.

## איך מוסיפים שינוי

```bash
supabase migration new <שם_באנגלית>     # יוצר <timestamp>_<שם>.sql כאן
# כותבים את ה-SQL בקובץ שנוצר
npm run db:lint-migrations              # מוודא שאין מספרים כפולים
supabase migration list --linked        # מראה מה מוחל ומה ממתין
supabase db push --linked               # מחיל על הפרודקשן
```

המעקב נעשה בטבלה `supabase_migrations.schema_migrations` שה-CLI מנהל.
הוא מתחבר דרך תפקיד זמני שהוא מקצה לעצמו, ולכן **אין צורך בסיסמת DB**.

## כללים

**אף פעם לא לערוך קובץ שכבר הורץ.** אחרי `db push` הקובץ נעול — שינוי
דורש מיגרציה חדשה. הריפו הזה הגיע למצב שהגיע אליו בדיוק כי קבצים נערכו
והורצו ידנית מחוץ למעקב.

**להריץ רק דרך `db push`, לא ב-SQL Editor.** הרצה ידנית לא נרשמת בטבלת
המעקב, וזה מה שגרם לניתוק בין הריפו לפרודקשן.

**לבדוק `--dry-run` לפני push לפרודקשן.**

**זרעים אינם מיגרציות.** הם ב-`supabase/seeds/` ולא רצים בשרשרת.
