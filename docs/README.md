## התחלה מהירה

```bash
npm install
cp .env.example .env.local   # ולמלא ערכים אמיתיים
npm run dev                  # http://localhost:3000
```

## מסמכים היסטוריים

מסמכי תכנון ישנים (IMPLEMENTATION_PLAN, DATABASE_AUDIT ועוד) הועברו ל-`docs/archive/`.
מסמכים אלה משקפים תכנון עבר ולא בהכרח את המצב הנוכחי — המקור האמין הוא התיקייה הזו.
