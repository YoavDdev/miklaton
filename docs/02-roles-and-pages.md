# 02 — תפקידים, הרשאות ודפים

## מנגנון האימות

1. משתמש מתחבר ב-`/login` (אימייל + סיסמה) → אימות מול **Supabase Auth**.
2. המערכת שולפת פרופיל מטבלת `user_profiles` ובודקת סטטוס (`pending` / `active` / `suspended`).
3. נחתם **JWT מותאם** (תוקף 8 שעות) עם `userId`, `role`, `fullName` — נשמר בעוגיית `auth-token` (HttpOnly).
4. `middleware.js` מאמת את הטוקן בכל בקשה לנתיב מוגן, בודק סטטוס עדכני מול Supabase (משתמש מושעה מנותק מיד), ואוכף הרשאות לפי תפקיד.
5. משתמש חדש שנרשם ב-`/register` נוצר כ-`operator` בסטטוס `pending` — עד אישור אדמין.

קבצים רלוונטיים: `middleware.js`, `lib/auth.js` (צד שרת), `lib/auth-edge.js` (Edge/jose), `app/api/auth/*`.

## זרימות משתמש מרכזיות

### מוקדן בשגרה
התחברות → `/operator` → מדריך שיחות לפי קטגוריה → איתור איש קשר זמין → משימות ועדכונים יומיים → צ'אט AI לשאלות.

### מוקדן בחירום
אזעקה → הפעלת נוהל ב-FlowRunner → מעקב שלב-אחר-שלב + לוג → חיפוש מקלט לתושב שמתקשר → עדכון סטטוס מקלטים.

### אירוע חירום
מנהל פותח אירוע ב-`/events` → נשלח קישור הזמנה → משתתפים מצטרפים דרך `/event/join/[token]` → כולם רואים יומן חי ומפה → סגירת אירוע ותחקיר.

### תורנות שבועית
מנהלת המוקד שולחת קישורי WhatsApp למנהלי מחלקות → כל מנהל ממלא `/duty-form/[id]` → התורנויות מוצגות למוקדן וב-`/on-call-query`.
