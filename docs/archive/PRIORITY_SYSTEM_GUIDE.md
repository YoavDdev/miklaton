# 🎯 מערכת עדיפות וניהול כוננים חכמה

## 📋 סקירה כללית

המערכת מאפשרת למנהל המוקד להגדיר **מי הכונן הנכון בזמן הנכון** עם escalation אוטומטי.

---

## 🔑 מושגי מפתח

### **1. Priority Order (עדיפות)**
- **1** = ראשון בתור
- **2** = שני בתור (אם הראשון לא זמין)
- **3** = שלישי בתור (אם השני לא זמין)

### **2. Contact Type (סוג כונן)**
- **escalation** = להקפצה (יש להתקשר אליו)
- **notification** = לעדכון בלבד (רק להודיע, לא להקפיץ)

### **3. Available Days/Hours (זמינות)**
- **available_days**: אילו ימים בשבוע (0=ראשון, 6=שבת)
- **available_hours_start/end**: שעות זמינות

### **4. Notes for Operator (הערות למוקדן)**
- הוראות מיוחדות שמוצגות למוקדן
- דוגמה: "להקפיץ רק במקרה של יותר מ-3 פנסים"

## 🚀 איך זה עובד?

### **1. המוקדן פותח "מדריך פניות"**
- בוחר קטגוריה (לדוגמה: חשמל)
- המערכת מציגה **רק את הכוננים הזמינים כרגע**

### **2. המערכת מסננת אוטומטית**
```javascript
// בודק:
1. האם הכונן בחופש? ❌ לא מציג
2. האם הכונן סומן "לא זמין"? ❌ לא מציג
3. האם היום הנוכחי בימי הזמינות? ✅
4. האם השעה הנוכחית בשעות הזמינות? ✅
5. ממיין לפי priority_order ✅
```

### **3. המוקדן רואה**
```
⚡ חשמל

📞 כונן קבלן - 053-7728451
   🟣 עדיפות 1
   💡 ראשון בתור בשישי-שבת
   [📋 העתק] [📞 חייג] [❌ לא זמין]

📞 אחראי כוננים יהודה - 054-4926910
   🟣 עדיפות 2
   💡 שני בתור (אם קבלן לא זמין)
   [📋 העתק] [📞 חייג] [❌ לא זמין]
```

### **4. כפתור "לא זמין"**
- המוקדן לוחץ "❌ לא זמין" על הכונן הראשון
- המערכת מסמנת אותו כ-`currently_unavailable`
- **אוטומטית** הכונן הבא בעדיפות מופיע ראשון!
