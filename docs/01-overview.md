# 01 — סקירת מערכת

## מה זה מקלטון?

**מקלטון** היא מערכת ניהול מוקד עירוני ואירועי חירום עבור עיריית יהוד-מונוסון.
המערכת התחילה ככלי לניהול מקלטים בזמן אזעקות, והתפתחה לפלטפורמה מלאה לניהול שגרת המוקד העירוני 24/7.

## מה המערכת צריכה לעשות?

### 1. שגרה יומית של המוקד (ליבת המערכת)
- **מדריך שיחות (Call Guide)** — קטגוריות פניות (מים, ביוב, רווחה, פיקוח...) עם אנשי קשר לפי סדר אסקלציה, זמינות לפי יום/שעה, חופשות והחלפות.
- **תורנויות ואנשי קשר** — לוח תורנויות שבועי לכל מחלקה, שאילתת "מי תורן עכשיו", טפסי תורנות למנהלי מחלקות (כולל קישורי WhatsApp).
- **משימות מוקדנים** — מנהלת המוקד מקצה משימות; מוקדנים מעדכנים סטטוס.
- **עדכונים יומיים** — חסימות כבידה, אירועים, עבודות תשתית — מוצגים למוקדנים לפי חלון זמן.
- **חיפושים תפעוליים** — לחצני מצוקה (גנים/בתי ספר/מוסדות), פינוי גזם ואשפה לפי רחוב, אנשי קשר.
- **סקרי שביעות רצון** — יצירת סקר עם קישור ציבורי, איסוף תשובות וייצוא ל-Excel.

### 2. חירום
- **מצב חירום (War Mode)** — מתג גלובלי שמשנה את התנהגות המערכת.
- **נהלי תפעול (FlowRunner)** — הדרכה שלב-אחר-שלב למוקדן בזמן אזעקה/רעידת אדמה, עם לוג פעולות.
- **חיפוש מקלטים** — מציאת 3 המקלטים הקרובים לכתובת תושב + מפה + סטטוס פתוח/סגור.
- **אירועי חירום** — פתיחת אירוע, הזמנת משתתפים בקישור/טלפון, יומן אירוע בזמן אמת (Realtime), מפה עם סימונים וחסימות, משימות שטח, העלאת תמונות.

### 3. מחלקת ביטחון
- **סידור עבודה שבועי** — שיבוץ פקחים/שיטור למשמרות (כולל ייבוא Excel).
- **פקודת יום** — סדר יום יומי הנגזר מהסידור השבועי, עם שינויים/החלפות ולוג שינויים.
- **חופשות צוות ביטחון** ומעקב "מי בשטח עכשיו" (מוצג למוקדן ולמסך).

### 4. מאגר ידע + AI
- **מאגר ידע** — ערכים מנוהלים על ידי מנהלת המוקד.
- **צ'אט AI (GPT-4o-mini)** — עוזר למוקדן: עונה על שאלות בהתבסס על מאגר הידע + נתונים חיים (תורנויות, פקודת יום, גזם, לחצני מצוקה, זמני שבת).

### 5. תצוגות
- **מסך מוקד (`/screen`)** — לוח תצוגה גדול: מזג אוויר, משמרות, תורנים, כוננים, חופשות, מצב חירום. מתרענן אוטומטית.
- **דשבורדים לפי תפקיד** — מנכ"ל, מנהלת מוקד, מנהל מכלול, מוקדן, פקח, אחראי מקלטים, אדמין.

## ארכיטקטורה

```
┌──────────────────────────────────────────────────┐
│  Next.js 14 (App Router, JavaScript, RTL)        │
│  ├── app/            דפים + API Routes           │
│  ├── components/     קומפוננטות React            │
│  ├── lib/            אימות, מרחקים, עירייה       │
│  └── middleware.js   הגנת נתיבים לפי תפקיד       │
├──────────────────────────────────────────────────┤
│  Supabase (PostgreSQL + Auth + Realtime+Storage) │
│  ~45 טבלאות (ראה 04-database.md)                 │
├──────────────────────────────────────────────────┤
│  שירותים חיצוניים:                               │
│  • OpenAI (צ'אט ידע) • Google Geocoding          │
│  • Open-Meteo (מזג אוויר) • Hebcal (זמני שבת)    │
└──────────────────────────────────────────────────┘
```

### סטאק טכנולוגי
| רכיב | טכנולוגיה |
|------|-----------|
| Frontend + Backend | Next.js 14.0.0 (App Router), React 18 |
| עיצוב | Tailwind CSS 3 (RTL) |
| בסיס נתונים | Supabase (PostgreSQL) + Realtime + Storage |
| אימות | Supabase Auth + JWT מותאם (jose / jsonwebtoken), עוגיית HttpOnly |
| מפות | Leaflet + react-leaflet (OpenStreetMap) |
| Excel | xlsx (ייבוא/ייצוא) |
| לוח שנה | react-big-calendar, date-fns |
| התראות UI | react-hot-toast |
| פריסה | Vercel |

### עיקרון רב-עירוניות (Multi-tenant)
המערכת בנויה לתמוך ביותר מעירייה אחת: טבלת `municipalities`, עמודת `municipality_id` בטבלאות המרכזיות,
ומשתני סביבה `NEXT_PUBLIC_MUNICIPALITY_*` שמגדירים שם, לוגו וצבעים (`lib/municipality.js`).
כיום פעילה עירייה אחת: יהוד-מונוסון.

## משתני סביבה (.env.local)

| משתנה | תיאור |
|--------|-------|
| `JWT_SECRET` | מפתח חתימת JWT (מינימום 32 תווים) — **חובה בפרודקשן** |
| `NEXT_PUBLIC_SUPABASE_URL` | כתובת פרויקט Supabase |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | מפתח anon |
| `SUPABASE_SERVICE_ROLE_KEY` | מפתח service role (צד שרת בלבד!) |
| `OPENAI_API_KEY` | לצ'אט הידע |
| `GOOGLE_MAPS_API_KEY` | לגיאוקודינג כתובות |
| `NEXT_PUBLIC_MUNICIPALITY_*` | שם/לוגו/צבעי העירייה |
| `NEXT_PUBLIC_EKRON_URL` | קישור למערכת עקרון |
| `APP_PASSWORD` / `ADMIN_PASSWORD` | סיסמאות מורשת (מנגנון ישן — ראה 07-maintenance.md) |

## פקודות

```bash
npm run dev     # שרת פיתוח
npm run build   # מייצר version.json ובונה לפרודקשן
npm start       # הרצת פרודקשן
npm run lint    # בדיקת lint
```
