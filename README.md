# מקלטון (Miklaton)

מערכת ניהול מוקד עירוני ואירועי חירום — עיריית יהוד-מונוסון.

🌐 דומיין: **www.miklaton.co.il**

## מה זה?

מקלטון היא פלטפורמה מלאה לניהול המוקד העירוני 24/7:

- 📞 **מדריך שיחות** — קטגוריות פניות עם אנשי קשר, אסקלציה וזמינות בזמן אמת
- 👥 **תורנויות וכוננים** — לוחות תורנות שבועיים, "מי תורן עכשיו", טפסי WhatsApp למנהלי מחלקות
- 🚨 **חירום** — מצב חירום, נהלי תפעול שלב-אחר-שלב, חיפוש מקלטים, אירועי חירום עם יומן חי ומפה
- 🛡️ **מחלקת ביטחון** — סידור עבודה שבועי, פקודת יום, חופשות, מעקב כוחות בשטח
- 🤖 **מאגר ידע + AI** — צ'אט חכם למוקדן על בסיס מאגר ידע ונתונים חיים
- 📊 **ניהול** — משימות מוקדנים, עדכונים יומיים, סקרי שביעות רצון, לחצני מצוקה, פינוי גזם
- 🖥️ **מסך מוקד** — לוח תצוגה גדול לחדר המוקד

## התקנה מהירה

```bash
npm install
cp .env.example .env.local   # למלא ערכים אמיתיים (ראה docs/01-overview.md)
npm run dev                  # http://localhost:3000
```

## סטאק

Next.js 14 (App Router) · React 18 · Tailwind CSS (RTL) · Supabase (PostgreSQL + Auth + Realtime + Storage) · OpenAI · Leaflet · Vercel

## מבנה הפרויקט

```
miklaton/
├── app/              # דפים + API Routes (App Router)
├── components/       # קומפוננטות React
├── lib/              # אימות, מרחקים, הגדרות עירייה
├── data/             # נתונים סטטיים (מקלטים, רחובות, נהלים)
├── supabase/         # סכמה, מיגרציות ו-seeds
├── scripts/          # סקריפטי תחזוקה ו-SQL (archive/ = חד-פעמיים)
├── docs/             # 📚 הדוקומנטציה (archive/ = מסמכים היסטוריים)
├── archive/          # קבצים ישנים שאינם בשימוש
└── middleware.js     # הגנת נתיבים לפי תפקיד
```
